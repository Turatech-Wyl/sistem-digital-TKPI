# Panduan TU

Panduan singkat pemakaian harian dan langkah saat ada masalah. Untuk TU dan kepala sekolah.

## Rutinitas

| Kapan | Yang dilakukan |
|---|---|
| **Tiap hari** | Buka **Pembayaran** → antrean verifikasi. Cocokkan foto bukti dengan mutasi bank, lalu klik **Terima** atau **Tolak** (isi alasannya). Kwitansi terkirim otomatis ke WA orang tua. |
| **Tiap hari** | Buka **WhatsApp** → tab **Perlu dibalas**. Balas dari aplikasi atau dari HP sekolah. |
| **Tanggal 1** | Tagihan bulan baru dibuat otomatis pukul 00.05. Cek di **Pembayaran**. Jika belum ada, klik **Buat tagihan**. Tombol ini aman diklik ulang karena tagihan tidak akan dobel. |
| **Tanggal pengingat** | Pengingat terkirim sendiri pukul 07.00–09.00. Tidak perlu melakukan apa pun. |
| **Akhir bulan** | **Laporan** → unduh rekap SPP dan buku kas (PDF/Excel) untuk kepala sekolah. |
| **Saat ada pembayaran tunai** | **Pembayaran** → catat bayar tunai. Kwitansi dicetak dan dikirim ke WA. |

## Aturan berbagi nomor dengan bot

- Bot hanya menjawab pertanyaan rutin: tagihan, rekening, riwayat, kwitansi, dan salam.
- Jika Anda membalas sebuah chat dari HP, bot **diam 10 menit** di chat itu.
- Pesan bot selalu diakhiri "— Asisten TK". Pesan tanpa tanda itu berarti dari Anda.

## Jika ada masalah

| Gejala | Langkah |
|---|---|
| Bot salah menjawab atau terlalu banyak membalas | Klik **Jeda bot** (Pengaturan/Dashboard). Semua balasan otomatis dan pengingat langsung berhenti, sedangkan balasan Anda tetap terkirim. Hubungi pengembang. |
| Dashboard menampilkan **WA Putus** | Tunggu 5 menit karena agent menyambung ulang sendiri. Jika masih putus, buka **Pengaturan → WhatsApp**, lalu scan QR dari HP sekolah (WhatsApp → Perangkat tertaut → Tautkan perangkat). |
| QR tidak muncul atau kedaluwarsa | Klik **Minta QR baru**, tunggu 10–30 detik. |
| HP sekolah mendapat peringatan dari WhatsApp | Segera **Jeda bot**, lalu hubungi pengembang. Sementara itu pakai tombol **wa.me** di aplikasi untuk mengirim manual. |
| Bukti dari orang tua dengan 2 anak tidak tertaut | Buka antrean verifikasi, pilih siswanya, lalu verifikasi seperti biasa. |
| Lupa password | Hubungi pengembang. Setelah login, password bisa diganti di **Akun**. |
| Aplikasi tidak bisa dibuka | Hubungi pengembang. |
