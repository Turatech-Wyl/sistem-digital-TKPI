# web

Aplikasi Next.js untuk TU dan kepala sekolah. Panduan setup, struktur, dan cara menjalankan ada di [README utama](../README.md); spesifikasi di [PRD](../PRD.md).

```sh
npm run dev         # http://localhost:3000
npm run build && npm run start   # produksi (PORT=3001 lewat scripts/start.sh)
npm run db:migrate  # prisma migrate dev
npm run db:seed     # isi data contoh
```
